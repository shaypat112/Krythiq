# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Report it privately through this repository's **Security** tab by selecting
**Report a vulnerability**. Include the affected component, reproduction
steps, potential impact, and any suggested remediation.

Please avoid accessing, modifying, or retaining other users' data while
researching an issue. We will acknowledge a report as soon as practical and
coordinate disclosure after a fix is available.

## Supported versions

Security fixes are applied to the latest version on the default branch.
